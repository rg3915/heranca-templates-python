Herança de Templates com Jinja2

Entenda como funciona a herança de templates e reutilização de código

O que é Jinja2?

Jinja2 é um motor de templates moderno e amigável para Python. Ele permite criar templates HTML dinâmicos com uma sintaxe simples e elegante, separando a lógica de apresentação do código Python.

Jinja2 é amplamente utilizado em frameworks web como Flask e pode ser usado standalone, como neste projeto.

Recursos do Jinja2 Utilizados

1. Herança de Templates

Permite criar um template base e estender em páginas específicas.

{% raw %}{% extends "base.html" %}{% endraw %}

2. Blocos de Conteúdo

Define seções que podem ser sobrescritas em templates filhos.

{% raw %}{% block content %}
  ...conteúdo...
{% endblock %}{% endraw %}

3. Includes

Inclui componentes reutilizáveis como navbar, footer, etc.

{% raw %}{% include 'includes/navbar.html' %}{% endraw %}

4. Variáveis

Exibe dados dinâmicos passados do Python.

{{ "{{ variavel }}" }}
{{ "{{ objeto.atributo }}" }}

5. Estruturas de Controle

Loops e condicionais para lógica de apresentação.

{% raw %}{% for item in lista %}
  {{ item }}
{% endfor %}

{% if condicao %}
  ...
{% endif %}{% endraw %}

6. Filtros

Transformam valores antes de exibi-los.

{{ "{{ texto|upper }}" }}
{{ "{{ lista|length }}" }}

Como Funciona a Herança

1. Template Base (base.html)

Define a estrutura HTML principal com blocos que podem ser sobrescritos:

<!DOCTYPE html>
<html lang="pt-BR" data-theme="light">
<head>
    <title>{% raw %}{% block title %}{% endblock %}{% endraw %}</title>
    <link rel="stylesheet" href="https://cdn.../pico.min.css">
    {% raw %}{% block extra_css %}{% endblock %}{% endraw %}
</head>
<body>
    {% raw %}{% include 'includes/navbar.html' %}{% endraw %}

    <main class="container">
        {% raw %}{% block content %}{% endblock %}{% endraw %}
    </main>

    <footer class="container">
        {% raw %}{% block footer %}{% endblock %}{% endraw %}
    </footer>

    {% raw %}{% block extra_js %}{% endblock %}{% endraw %}
</body>
</html>

2. Template Filho (exemplo: index.html)

Estende o base.html e sobrescreve os blocos necessários:

{% raw %}{% extends "base.html" %}

{% block title %}Página Inicial{% endblock %}

{% block content %}
    <h1>Conteúdo da página</h1>
    <p>Olá, {{ nome }}!</p>
{% endblock %}{% endraw %}

3. Configuração no Python (app.py)

Configurando o Jinja2 e renderizando templates:

from jinja2 import Environment, FileSystemLoader

# Configurar o ambiente Jinja2
env = Environment(loader=FileSystemLoader('templates'))

# Carregar e renderizar template
template = env.get_template('index.html')
html = template.render(
    nome='Regis',
    videos=[...]
)

Vantagens da Herança de Templates

Reutilização de Código

Evite duplicação definindo uma vez a estrutura HTML, CSS e JavaScript comum a todas as páginas.

Manutenção Facilitada

Altere o layout em um único lugar (base.html) e todas as páginas são atualizadas automaticamente.

Consistência Visual

Garanta que todas as páginas sigam o mesmo padrão de design e estrutura.

Organização

Separe concerns: estrutura base, componentes e conteúdo específico de cada página.

Flexibilidade

Cada página pode sobrescrever apenas os blocos necessários, mantendo o resto do template base.

Componentes Reutilizáveis

Use includes para compartilhar componentes como navbar, sidebar, cards, etc.
